E:\클로드작업\_AGENT\tools\ 에 있는 guard.py, handoff_load.py, handoff_end.py 를 ~/.claude/settings.json 훅으로 등록해줘.
1. 수정 전에 settings.json 을 settings.json.bak_20261105 로 백업한다.
2. 기존 훅(audit_brief_guard.py, backlog_brief.py, feedback_nudge.py, gate.py 등)은 지우지 말고 각 배열에 항목만 추가한다.
3. PreToolUse — matcher: Bash|Write|Edit|MultiEdit|NotebookEdit / 명령: python "E:/클로드작업/_AGENT/tools/guard.py"
4. SessionStart — 명령: python "E:/클로드작업/_AGENT/tools/handoff_load.py"
5. SessionEnd — 명령: python "E:/클로드작업/_AGENT/tools/handoff_end.py"
6. 핸드오프 폴더는 G:\내 드라이브\_핸드오프 다(스크립트가 자동으로 찾는다). 작업 폴더마다 CLAUDE.md 에 「핸드오프 키: <claude.ai 프로젝트와 같은 키, 밑줄 없이>」 한 줄이 있으면 그 키를 쓰고, 없으면 폴더 이름을 키로 쓴다. 파일명은 HANDOFF_<키>_<업무>_YYYYMMDD_HHMM.md 이고, 세션 시작 시 업무별 최신본 목록이 나온다.
7. SessionStart 의 backlog_brief.py 는 BACKLOG.md 전문 대신 G:\내 드라이브\_피드백백로그\ACTIVE_RULES.md 를 출력하도록 고친다(원본은 판 번호를 붙여 보관).
8. 끝나면 시험한다: guard.py 에 위험 명령 JSON 을 넣어 종료코드 2, 일반 명령은 0 이 나오는지 / handoff_load.py 에 {"cwd": "<작업 폴더>"} 를 넣어 출력이 나오는지 확인하고 결과를 보고한다.
