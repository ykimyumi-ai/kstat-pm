E:\클로드작업\_AGENT\설치_토큰가드\ 의 파일로 로컬 Claude Code의 토큰 낭비를 줄여줘. 바꾸는 파일은 모두 먼저 같은 폴더에 .bak_날짜 사본을 만들고, 기존 내용은 지우지 말고 추가·교체 범위만 고친다. 삭제는 하지 말고 필요하면 _보관으로 옮긴다.

1. 파일 설치
   - token_guard.py, hook_throttle.py, scope_guard.py 를 E:\클로드작업\_AGENT\tools\ 로 복사한다.
   - task-intake.zip 을 ~/.claude/skills/ 아래에 풀어 ~/.claude/skills/task-intake/SKILL.md 가 되게 한다. 같은 이름 폴더가 있으면 이름 뒤에 _old_날짜 를 붙여 옮긴다.

2. ~/.claude/settings.json 훅 등록(기존 훅은 모두 유지하고 배열에 항목만 추가)
   - PreToolUse — matcher: Agent|Task|Read|Bash / 명령: python "E:/클로드작업/_AGENT/tools/token_guard.py"
   - token_guard.py 는 경고만 하고 막지 않는다(항상 종료 코드 0).
   - PreToolUse — matcher: Bash|Write|Edit|MultiEdit|NotebookEdit / 명령: python "E:/클로드작업/_AGENT/tools/scope_guard.py" (기존 guard.py 항목 옆에 추가)
   - scope_guard.py 는 프로젝트 폴더의 .claude/night_scope.json 이 있을 때만 작동한다. 파일이 없거나 expires 가 지났으면 아무것도 하지 않는다. 지금은 범위 파일을 만들지 않는다(야간 실행 때 만든다).

3. 기존 훅 4종에 냉각 넣기. 훅 원문은 E:\클로드작업\_AGENT\tools\ 의 audit_brief_guard.py · backlog_brief.py · feedback_nudge.py · gate.py 와 ~/.claude/settings.json 에 등록된 Stop·UserPromptSubmit 훅 전체를 직접 읽고, 어느 파일이 아래 4개 알림을 내는지 먼저 표로 보여 준다. 표를 보여 준 뒤 이어서 고친다.
   각 훅 맨 위에 다음을 넣는다:
       import sys; sys.path.insert(0, r"E:/클로드작업/_AGENT/tools")
       from hook_throttle import should_fire
   (a) Stop 「감사 게이트」(감사 미완료 알림)
       - 감사 대상 목록에서 경로에 _이전판 · _보관 가 들어가거나, 파일명이 t숫자.pptx · ~$로 시작 · test로 시작 · 임시로 시작하는 것을 뺀다.
       - 남은 대상 경로를 정렬해 하나의 문자열로 만들고 should_fire("audit_gate", 그 문자열, 1800) 이 False 면 아무것도 출력하지 않고 종료 코드 0 으로 끝낸다. 같은 대상 집합의 알림은 30분에 1회만 나가게 한다.
   (b) 「[등재 점검]」(지적 표현 감지)
       - 알림이 가리키는 핸드오프 파일(HANDOFF_survey-ontology.md 등)의 경로가 어디서 정해지는지 진단한다. 과업 폴더의 CLAUDE.md 「핸드오프 키」를 쓰도록 고치고, 진단 결과(원인 줄)를 보여 준다.
       - 「맞아?」 「이거 맞나」처럼 확인을 묻는 질문형은 지적 판정에서 뺀다. 지적 판정은 오류·틀렸다·잘못·수정해 같은 명시적 표현으로 한정한다.
       - 사용자 프롬프트 하나에 알림은 1회만: should_fire("feedback_nudge", 프롬프트 앞 80자, 1800).
   (c) 「금칙어」 알림
       - 같은 인용·같은 금칙어는 should_fire("banned_word", 금칙어+파일경로, 1800) 로 30분에 1회만 낸다. 따옴표 안 인용문은 판정에서 뺀다.
   (d) 「시각 점검」 알림
       - 같은 파일 해시(또는 경로+수정시각)는 should_fire("visual_check", 파일경로+수정시각, 1800) 로 30분에 1회만 낸다.
   각 수정 뒤 .bak_날짜 사본이 있는지 확인하고, 고친 줄을 나란히 보여 준다.

4. 시험하고 보고한다(지어내지 말고 실제 출력을 붙인다)
   - token_guard.py: PreToolUse JSON 한 줄을 넣어 종료 코드 0, 깨진 입력도 종료 코드 0. 큰 transcript 를 만들어 「컨텍스트 약 …k 토큰」 경고가 한 번만 나오는지.
   - 훅 4종: 같은 입력을 연속 2회 넣어 두 번째는 출력이 없는지, 서로 다른 입력은 각각 나오는지.
   - 감사 게이트: _이전판 폴더 안 파일만 있을 때 알림이 안 나오는지.
   - scope_guard.py: 임시 폴더에 night_scope.json(mode block, allow 폴더 하나)을 만들고, 허용 폴더 안 쓰기는 종료 코드 0, 밖 쓰기는 종료 코드 2, 범위 파일이 없으면 0. 시험 뒤 임시 범위 파일을 지운다(이동이 아니라 임시 파일이므로 삭제 가능).
   - /skills 목록에서 task-intake 가 v1.4 로 보이는지.
   - 적용 못 한 것은 이유와 함께 「미적용」으로 적는다.

5. 끝나면 변경한 파일 목록과 되돌리는 방법(.bak 경로)을 표로 보여 준다.
