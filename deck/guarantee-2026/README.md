# 2026 소상공인 실태조사 인포그래픽 — 편집 가능한 PPTX

원본은 텍스트 레이어가 없는 **이미지 PDF 4장**(768×1152pt = 10.667×16in, 2:3)이다.
글자 한 자도 고칠 수 없어, 모든 글자·도형을 네이티브 PPT 객체로 다시 만든다.
**그래프는 파워포인트 정식 차트**라 차트를 고르고 `데이터 편집`을 누르면 엑셀이 열리고,
값을 고치면 막대 길이와 값 라벨이 함께 바뀐다.

```bash
node build.js --only g01     # 1장만
node build.js                # 전체
python3 verify.py            # 구조·원문·차트 검증
bash tools/render.sh /tmp/gr # 원본과 같은 크기(1600×2400)로 렌더
```

pptxgenjs 는 옆 덱(`../namp-2026/node_modules`)의 것을 쓴다. 두 덱의 버전이 갈리면
산출물도 갈리므로 일부러 하나만 둔다.

## 좌표계

원본을 150dpi 로 렌더한 **1600×2400px** 의 픽셀을 그대로 쓴다(1px = 1/150in = 0.48pt).
`theme.js` 의 스케일러가 인치로 환산하므로 슬라이드 코드에는 눈대중 값이 없다.

글자 크기는 원본에서 잰 **잉크 높이(px)** 로 적는다. `FS()` 는 한글, `FSD()` 는
숫자용이다. 두 비율(0.945 / 0.83)은 추정이 아니라 KoPub돋움체 Bold 를 실제로 렌더해
잉크 높이를 재서 얻은 값이다.

## 측정 도구

| 도구 | 쓰임 |
|---|---|
| `tools/measure.py` | 색 계열 연결성분 → 카드·필·배지 상자 (팔레트만 이 덱 것으로 교체) |
| `tools/profile.py` | 가로·세로 한 줄을 훑어 색이 바뀌는 지점 — 흰 카드의 옅은 테두리를 찾는다 |
| `tools/ink.py` | 구역 안 글줄의 잉크 상자 — 그림이 섞여 있어도 글줄만 골라낸다 |
| `tools/bbox.py` | 일러스트 크롭 범위 |
| `tools/cmp.py` | 원본과 렌더의 같은 구역을 나란히 재서 Δx·Δy·Δw 를 뽑는다 |
| `tools/overlay.py` | 원본 잉크는 빨강, 렌더는 파랑으로 겹쳐 그린 대조 이미지 |
| `tools/extract-assets.py` | 일러스트·아이콘 크롭 → `assets/` |

## 차트 규약

`charts.js` 를 반드시 거친다. 18개 차트에 옵션을 손으로 붙이면 반드시 갈린다.

- 축선·눈금선·범례 없음. 배경은 투명 대신 **얹히는 면과 같은 색**으로 채운다
  (kstat-ppt 가 transparency 를 금지한다).
- 값 라벨은 **차트가 그린다.** 글상자로 따로 두면 데이터를 고쳐도 숫자가 안 바뀐다.
- 가로 막대는 배열을 뒤집어 넣는다 — 네이티브 가로 막대는 첫 항목을 맨 아래에 그린다.
- 차트 틀은 항목 이름을 품지 않는다. 항목 이름과 아이콘은 차트 밖 네이티브 객체다.
  축 라벨을 차트에 맡기면 파워포인트가 라벨 칸 폭을 제 마음대로 잡는다.

## 원본과 다른 점

1. **글꼴** — 원본 제목은 기하학적 헤비 고딕(ㅇ이 정원, ㅊ 윗획이 수평)이나 사내 표준인
   **KoPub돋움체**로 만든다. 앞의 제안서 덱 21장과 같은 선택이다.
2. **글자 폭** — KoPub돋움체가 원본 글꼴보다 5~15% 넓다. 잉크 높이를 맞추면 줄이
   길어져, 칸을 넘치는 자리는 한 단계 줄여 넣는다(`fit`·`bigValue`).
3. **한글↔숫자 사이 간격** — 파워포인트·LibreOffice 는 동아시아 문자와 서양 문자가
   맞닿으면 약 0.25em 을 자동으로 넣는다. `1억 3,703만원`·`2회 이상`·`(인수 포함)`
   처럼 원본보다 살짝 벌어진다. 렌더러 기능이라 끌 수 없다.
4. **도넛 바깥 큰 숫자** — `41.0%` 같은 콜아웃은 차트 라벨로 그 자리에 놓을 수 없어
   글상자로 둔다. 데이터를 고치면 링은 바뀌지만 이 숫자는 함께 바뀌지 않는다.
5. **차트 크기** — 렌더러가 플롯 영역에 여백을 두어 실제 링·막대가 틀보다 5~7% 작다.
   틀을 그만큼 키워 잡았다. 파워포인트와 LibreOffice 의 여백이 달라 미세한 차이가 난다.
6. **지면 배경** — 원본의 아주 옅은 그라데이션 → 단색 `FBFCFE`.
7. **점선 구분선** — 1장 세 칸 사이의 점선은 옅은 실선으로 그린다.
8. **일러스트** — 사람·건물·돈다발은 원본 크롭 PNG 다. 크게 키우면 흐려진다.
   1장 머리의 구름 한 조각은 부제 글자와 겹쳐 따로 잘라 이어 붙였다.
