✉ Gmail 일정 가져오기
Google 계정 직접 연동 · Claude 불필요
⚙ 최초 1회 설정 (약 10분)
1. console.cloud.google.com 접속 후 새 프로젝트 생성
2. API 및 서비스 → 라이브러리 → Gmail API → 사용 설정
3. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션
4. 승인된 자바스크립트 원본에 http://localhost 추가
5. OAuth 동의 화면 → 테스트 사용자에 본인 Gmail 추가
6. 생성된 클라이언트 ID 복사 후 아래 입력
✓ 설정값은 이 브라우저에 저장 — 다음부터는 바로 사용 가능
